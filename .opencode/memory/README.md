# ── patterns/ — Established Patterns ──────────────────────────────────
# Format: {pattern-name}.md
# Documents conventions discovered in this project.
#
# Example: nestjs-di-pattern.md
# ```markdown
# # Pattern: NestJS DI for Interface-Based Ports
# **Scope**: api/src/application, api/src/infrastructure
# **Status**: established
#
# ## Context
# NestJS cannot resolve TypeScript interfaces via reflection (erased at runtime).
#
# ## Solution
# Always use @Inject('TokenName') on constructor parameters that are interfaces.
# Register the implementation with `provide: 'TokenName', useClass: ImplClass`.
#
# ## Example
# \```ts
# constructor(@Inject('UserRepository') private readonly repo: UserRepository) {}
# \```
# ```

# ── learnings/ — Gotchas and Discoveries ──────────────────────────────
# Format: YYYY-MM-DD-{slug}.md
# Captures non-obvious technical discoveries.
#
# Example: 2026-05-18-cors-mixed-content.md
# ```markdown
# # Learning: Mixed Content Blocks HTTPS→HTTP Requests
# **Date**: 2026-05-18
# **Context**: Web (sesitec.net HTTPS) calling API (86.48.23.197 HTTP)
# **Discovery**: Browsers block HTTP requests from HTTPS pages.
# **Solution**: PHP reverse proxy on Hostinger to keep requests same-origin.
# **Affected**: web/.env.production, deploy/v1-proxy.php
# ```
